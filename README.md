# Space Game

Проста гра на JavaScript: потрібно знищувати кораблі чужинців, які спускаються зверху вниз.

## Як запустити

Відкрити папку з грою у VS Code, встановити розширення **Live Server** і натиснути «Go Live» (або Open with Live Server на index.html). Просто відкрити index.html подвійним кліком не вийде, бо використовуються модулі (import).

## Як грати

1. Обрати швидкість у списку (1–8) і натиснути Start.
2. Стрілки вліво й вправо рухають кораблик.
3. Пробіл — постріл. Промінь знищує найнижчого ворога в тій самій колонці.
4. За кожного знищеного ворога дається 100 очок.
5. Кожні 1000 очок швидкість ворогів збільшується.
6. Перемога при 5000 очок. Програш, якщо вороги дійшли до рядка кораблика.

## Файли

- index.html — сторінка (поле, рахунок, вибір швидкості, кнопка Start)
- style.css — стилі
- Ship.js — клас корабля
- script.js — логіка гри

## Налаштування

Усі константи на початку script.js : розмір квадрата (`SIZE`), розмір поля (`COLS`, `ROWS`), очки за ворога (`POINTS_PER_KILL`), очки для перемоги (`WIN_SCORE`), кольори ворогів (`COLORS`).
